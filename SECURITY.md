# Security Policy

## Supported versions

Security and privacy fixes are made against the latest release of Watch Your
Language. Please update to the newest available version before reporting a
problem that may already have been resolved.

## Reporting a vulnerability

Please report suspected security or privacy vulnerabilities privately by
emailing `humphreywcurtis@gmail.com` with the subject “Watch Your Language
security”. Do not open a public GitHub issue for a vulnerability.

Include the affected app version, device and operating-system versions, steps
to reproduce the issue, its likely impact and any suggested mitigation. Do not
send real health information, private phrases, credentials or other sensitive
personal data. Use sample data when demonstrating the problem.

You should receive an acknowledgement within seven days. Please allow time for
the issue to be investigated and a fix to be prepared before publishing
details.

For ordinary bugs and accessibility suggestions, use
[GitHub Issues](https://github.com/HumphreyCurtis/Watch-Your-Language-AAC/issues).
